Run Locally from Source

# Clone and run locally from source (Node >= 20 LTS + Rust stable + wasm32)
git clone https://github.com/jcusoftware/solo.git
cd solo
npm ci
cp .dev.vars.example .dev.vars
npm run db:migrate:local
npm run render
npm run dev

Three-Plane Cloudflare-Native Architecture

SWS separates authoring, optional collaborative control, and ultra-lean published edge sites so visitor traffic never pays runtime CMS overhead.

1. Build & Authoring Plane

Author sites declaratively with sws-ir, pure-Rust sws-css, and deterministic sws-compiler. Use the unified solo CLI and local stdio MCP server for CI and AI-assisted editing.

2. Edge Published-Site Plane

Published HTML, CSS, and JSON-LD serve straight from Cloudflare Workers Static Assets. Only /api/* routes invoke the Rust/Wasm Worker for Turnstile verification, D1 storage, and optional notifications.

3. Studio & Rust Export

Upcoming milestones add sws-worker-studio (D1, R2, Queues, SQLite Durable Objects) and a pure-Rust/Wasm visual canvas with solo export emitting standalone Rust Cloudflare Worker apps.
