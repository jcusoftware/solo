Getting Started

Get Solo Website System running locally in minutes using free-tier tools and zero paid cloud dependencies.

Prerequisites

Tool Requirement Install / Setup
Node.js LTS >= 20 nvm use --lts
Rust stable + Wasm target wasm32-unknown-unknown rustup target add wasm32-unknown-unknown
worker-build ^0.9 cargo install worker-build@^0.9 --locked
cargo-deny Latest stable cargo install cargo-deny --locked
Playwright Chromium For E2E & axe gates npx playwright install chromium

Ensure ~/.cargo/bin is on your PATH

wrangler dev invokes worker-build to compile the Rust Worker to WebAssembly. Add export PATH="$HOME/.cargo/bin:$PATH" to your shell profile if worker-build is not found.

Option 1: Download a Prebuilt solo Binary

Tagged v* releases publish cross-compiled binaries for five targets (Linux (x86_64), Linux (ARM64), macOS (Apple Silicon), macOS (Intel), Windows (x86_64)) along with a SHA256SUMS.txt manifest. Visit the Download section or GitHub Releases.

# Verify integrity before running a downloaded archive
sha256sum -c --ignore-missing SHA256SUMS.txt
tar -xzf solo-<version>-<target>.tar.gz
./solo --help

Option 2: Run the Workspace from Source

git clone https://github.com/jcusoftware/solo.git
cd solo
npm ci
cp .dev.vars.example .dev.vars
npm run db:migrate:local
npm run render
npm run dev

Once wrangler dev finishes building the Rust/Wasm Worker, open http://127.0.0.1:8787 in your browser.

Smoke-Test the Local Edge API

The example .dev.vars.example uses Cloudflare's documented always-pass Turnstile test key for local development and stubs outbound Resend email delivery.

# 1. Health check
curl -s http://127.0.0.1:8787/api/health
# {"service":"sws-worker-site","status":"ok","version":"0.1.0-dev"}

# 2. Newsletter signup (requires explicit consent: true)
curl -s -H 'content-type: application/json' \
  -d '{"email":"guest@example.com","consent":true,"source_route":"/","cf-turnstile-response":"XXXX.DUMMY.TOKEN.XXXX"}' \
  http://127.0.0.1:8787/api/newsletter

# 3. Inspect local D1 rows
npx wrangler d1 execute DB --local \
  --command "SELECT email, status, consent_timestamp, source_route FROM newsletter_subscribers"

Run All Fast Quality Gates

npm run verify
cargo check --target wasm32-unknown-unknown -p sws-worker-site

With npm run dev running in another terminal, you can also run live header parity, Playwright axe-core WCAG 2.2 AA checks, and Lighthouse CI:

npm run check:headers:live
BASE_URL=http://127.0.0.1:8787 npm run test:a11y
npm run lhci
