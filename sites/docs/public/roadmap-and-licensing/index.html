Roadmap & Licensing

Planned milestones for Solo Website System and the permissive open-source licensing model that governs the core engine.

Release Roadmap

v0.1.0 — Core Rust Engine, CLI/MCP & Vertical Pack Foundation

  • sws-ir: Strongly typed, industry-agnostic Site IR (pages, sections, blocks, design tokens, routes, JSON-LD).
  • sws-css: Pure-Rust, permissively licensed CSS AST, validator, contrast checker, and emitter.
  • sws-compiler: Deterministic HTML/CSS compiler with built-in WCAG 2.2 Level AA structural enforcement.
  • sws-plugin: Stable plugin ABI for vertical IR transforms, renderers, and post-compile lint passes.
  • sws-cli & sws-wasm: Unified CLI, local stdio MCP server, and browser Wasm compiler bridge.
  • packs/hospitality: First vertical pack cleanly isolated from open-source core crates.

v0.2.0 — Cloudflare Control Plane & Real-Time Sync

  • sws-worker-studio: Multi-tenant Cloudflare Workers control plane with dual security-header parity and Turnstile protection.
  • D1 + R2 + Queues: Relational project/session metadata, immutable build & media storage, and async publish pipelines.
  • SQLite Durable Objects: ProjectRoom for collaborative real-time editing and RateLimiter for edge rate limiting.

v0.3.0 — Pure-Rust Visual Builder & Standalone Rust App Export

  • Pure-Rust Studio Frontend: Browser-based Rust/Wasm visual builder shell, live canvas, and workspace console compiling directly against sws-ir, sws-css, and sws-compiler.
  • Standalone Rust App Export (solo export): Emits self-contained Rust Cloudflare Worker applications (Cargo.toml, typed handlers, D1 migrations, static assets, and wrangler.jsonc).

Licensing

  • Open-source core, sites & reference pack (MIT OR Apache-2.0): Core Rust crates (crates/*, core/), builder applications (apps/*), core packages (packages/*), static sites (sites/*), and the reference hospitality pack (packs/hospitality) are dual-licensed under the MIT License and Apache License 2.0.
  • Dependency hygiene: cargo deny check enforces a strict permissive OSI license allowlist (MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Unicode-DFS-2016, CC0-1.0, plus narrowly scoped Unicode-3.0 entries for ICU/unicode crates). GPL, AGPL, LGPL, MPL, and source-available licenses are rejected.
  • External vertical packs: Third-party or external industry packs are decoupled behind sws-plugin and may be distributed on independent release tracks under their own licenses.
