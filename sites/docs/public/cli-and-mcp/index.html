CLI & MCP Reference

Solo provides a unified Rust CLI (solo) and local stdio Model Context Protocol (MCP) server for deterministic builds, validation, export, and AI-assisted editing.

Workspace tooling note

The pure-Rust sws-cli crate builds the solo binary (cargo run -p sws-cli -- ...). Equivalent workspace npm scripts are also available via npm run render, npm run check:headers, npm run lint:abc, and npm run sites:build.

solo Commands

Command Description
solo init <dir> [--pack <name>] Scaffold a starter Solo site project directory, optionally preconfigured for a vertical pack such as hospitality.
solo build <input> <outdir> [--check] Compile a SiteDocument IR or pack manifest into deterministic static HTML, CSS, JSON-LD, sitemap.xml, robots.txt, and _headers. Pass --check in CI to verify files byte-for-byte without writing.
solo check <input> [--headers-file <path>] [--json] Validate IR/pack schemas, run compiler WCAG 2.2 AA and plugin lint passes, and optionally check _headers parity against Rust SECURITY_HEADERS.
solo export <input> <outdir> Export a deployable Cloudflare Workers + Static Assets + D1 bundle (public/, wrangler.jsonc, and D1 SQL migrations).
solo mcp Start the local stdio JSON-RPC 2.0 MCP server for editor and AI-assistant integrations.

Example CLI Workflow

# Initialize a starter site
solo init ./my-site

# Validate IR, accessibility rules, and header parity (JSON report for CI)
solo check ./my-site/site.json --headers-file ./my-site/public/_headers --json

# Compile deterministic static output
solo build ./my-site/site.json ./my-site/public

# Export a Cloudflare-ready bundle
solo export ./my-site/site.json ./dist-bundle

Stdio MCP Server (solo mcp)

The built-in MCP server communicates over standard input/output using JSON-RPC 2.0 so coding agents can inspect and patch site IR deterministically without hand-editing rendered HTML.

MCP Tool Purpose
read_site_ir Load and validate a site IR or pack JSON file and return its normalized structure.
apply_ir_patch Apply structured patches to site IR while enforcing schema invariants.
compile_preview Compile the current IR in memory and return preview diagnostics and artifact summaries.
run_a11y_and_plugin_checks Run compiler accessibility checks and active vertical pack linters on the site IR.

Local MCP Client Configuration

{
  "mcpServers": {
    "solo": {
      "command": "solo",
      "args": ["mcp"]
    }
  }
}
